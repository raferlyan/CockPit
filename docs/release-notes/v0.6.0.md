## Cockpit v0.6.0

这一版让界面的显示与隐藏更顺滑，新增了操作日志，修复了文件传输窗口被长路径挤压的问题，并提供图文版产品使用说明书。

### 下载

| 系统 | 文件 |
|---|---|
| macOS（Apple 芯片） | `Cockpit-0.6.0-mac-arm64.dmg` |
| macOS（Intel） | `Cockpit-0.6.0-mac-x64.dmg` |
| Windows 10/11 | `Cockpit-0.6.0-win-x64.exe` |
| 产品使用说明书 | `Cockpit-v0.6.0-manual-zh-CN.pdf` |

安装包没有签名。macOS 首次打开如提示「无法验证开发者」，在 Finder 里右键 → 打开；Windows 如出现 SmartScreen 提示，点「更多信息 → 仍要运行」。

### 新功能

#### 操作日志
底部状态栏新增「操作日志」，点开后从右侧滑出面板，记录每次操作执行的 adb 命令，方便查阅和复制到别处使用：
- 记录的操作包括：上传、下载、浏览目录、remount、统计占用、进入 / 退出 root、截图、扫描 / 安装 / 卸载 / 停用 / 导出应用、投屏、打开 Shell / Logcat / 本机终端 / root 终端、录制 Trace、无线连接。
- 每条显示时间、设备、耗时和成败，失败时显示原因（包括部分文件上传失败）。
- 命令前的 `#` 注释说明用途，如「上传前检查目标目录」「root 会话中执行」「经 adb sync 协议传输，效果等同」。
- 命令已按 shell 规则加好引号，可以单条复制、复制整条操作或「复制全部」，粘贴到终端里直接执行；复制的文本里操作名称和设备写成注释。
- 支持搜索、按设备筛选、只看失败、清空；长的内部脚本默认折叠，点「展开」查看。
- 后台每秒的状态采集不会记录；su 时自动输入的密码不会出现在日志中。最多保留最近 300 条，关闭应用即清空。

#### 产品使用说明书
新增图文版说明书（17 章，31 张实机截图），覆盖安装、界面、各项功能、root 与 remount 的区别、常见问题和快捷键，提供 PDF 和 Markdown 两种格式，位于 `docs/manual/`，PDF 也随 Release 一起发布。

### 改进

#### 显示与隐藏动画
- 设备列表、设备信息和终端的收起 / 展开改为带回弹的弹性过渡；拖动分隔条时不做过渡，保持跟手。
- 对话框打开时遮罩淡入、窗口弹性放大；关闭时淡出缩小，不再瞬间消失。
- 右键菜单从鼠标位置弹出；通知从右侧滑入，关闭时收起高度，下面的通知平滑补上。
- 上传进度、失败提示、日志条目等区块出现时有淡入；按钮按下有轻微回弹。
- 系统开启「减少动态效果」时自动关闭动画。

#### 使用向导
新增「操作日志」一步，共 20 步。

### 问题修复

- **文件传输窗口被长路径挤压**：本地文件路径很长时，右侧的目标目录会被挤得很窄。现在左右两栏固定各占一半；本地文件改为两行显示（文件名 + 所在目录），目录过长时省略开头，鼠标悬停看完整路径。
- **本地文件路径的斜杠跑到末尾**：如 `/Users/me/a.mp4` 显示成 `Users/me/a.mp4/`，已修复。
- 设备目标目录一侧变窄时，「前往」按钮不再被拆成两行。

### 其它
