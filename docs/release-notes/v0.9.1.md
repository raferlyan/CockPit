## Cockpit v0.9.1

应用管理新增「运行中」筛选和状态标记。打开应用管理或点击「刷新运行状态」时，Cockpit 会读取设备进程，并把主进程和 `:service` 等子进程归到对应应用。运行中的应用可用行内「停止」按钮执行强制停止。

「一键清空后台」会在确认后请求 Android 清理后台进程，随后重新读取运行状态。系统服务可能自动重新启动。这个操作调用设备的 `am kill-all`，不会清除应用数据。

本版同时收录 Windows Terminal Preview 的 Cockpit ADB Shell 独立入口源码。该入口的体验 ZIP 仍可从 v0.9.0 的 Release 下载。
