## Cockpit v0.9.0

这一版把设备状态做成了能边操作边看、能回看、能留证据的性能监控：投屏画面上方新增负载条，新增前台应用的帧率与卡顿统计、单个应用的 CPU / 内存 / 线程曲线，曲线上会标出点击、应用切换、崩溃等事件；另外新增状态数据录制与回看、CSV / JSON 导出和阈值告警。

### 新功能

#### 投屏负载条
投屏时，画面上方显示 CPU（带最近 60 秒迷你曲线）、内存、CPU 温度，以及前台应用的包名、帧率和卡顿比例：
- 平时只显示这几项；IO 等待、资源压力偏高，或者出现温控、限频时，才会多出对应的项。
- 数值超过阈值时变色。点负载条展开右侧的完整状态面板。
- 投屏工具栏的「负载」可以开关，选择会被记住。

#### 前台应用的帧率与卡顿
状态面板新增「应用」区：
- 每 2 秒识别一次前台应用，每秒统计帧率、卡顿帧占比和帧耗时 P50 / P90 / P99，并画出最近 120 帧的耗时柱状图，超时的帧标红。
- 画面不动时显示「静止」，不显示 0 fps，以免误以为卡死。
- 普通界面（View、Compose）用 `dumpsys gfxinfo framestats` 统计。连续 3 秒没有新帧时，会临时打开 SurfaceFlinger 的 timestats，看是不是游戏、Flutter 这类 SurfaceView 在画；普通帧恢复后自动关掉。
- 只有负载条或状态面板正在显示时才采集帧数据。

#### 关注应用
- 默认跟随前台应用。在「应用」区点「固定」，或在进程表里点「关注」，可以固定采集某个应用，切到别的应用后也不会换。
- 显示这个应用所有进程（含 `:push` 等子进程）合计的 CPU，和整机 CPU 画在同一张图上；还有 RSS、PSS（只含主进程）、线程数和线程 Top 8。
- CPU、内存和线程数并在每秒那一条采集命令里读取，不增加 shell 调用。

#### 事件标记
所有曲线上用竖虚线标出事件，鼠标悬停显示说明：
- 投屏里的触摸、按键、滚动（1 秒内合并成一个），应用和 Activity 切换。
- 关注应用的进程启动和结束；所有应用的崩溃、ANR、低内存查杀。
- 超过 100 ms 的单帧卡顿；安装应用、录制 trace 等设备操作。
- 按 ⌘⇧M（Windows 上 Ctrl+Shift+M）手动打一个标记，焦点在投屏画面上时也能用。

新增「事件」列表，点一条可以把曲线放大到它前后 15 秒。

#### 录制与回看
- 点「● 录制」，把这台设备的负载、应用、帧率和事件持续写到 `文稿/Cockpit/Metrics`，不限时长，按钮上显示已录时长。
- 状态面板标题栏的「历史」里可以回看、在文件夹中显示或删除录制文件，删除会移到废纸篓。
- 回看时显示整个会话，可以拖选放大和导出，顶部的「返回实时」回到实时数据。

#### 导出 CSV / JSON
- CSV 每秒一行：每核占用和频率按核数展开成列，同一秒的关注应用、帧统计和事件也合并在这一行。带 BOM，用 Excel 打开中文不乱码。
- JSON 是完整的原始数据，适合用脚本分析。
- 放大了曲线就导出放大的区间，否则导出当前时间范围。

#### 告警
在「设置 → 告警」里逐条开关、调整阈值。默认规则：
- CPU 温度高于 45 ℃、可用内存低于 10%、频率上限低于硬件最高频率的 70%：持续 10 秒才告警。
- 前台应用卡顿帧高于 20%：持续 5 秒告警。
- 温控等级达到「中等」、单帧耗时超过 300 ms：立即告警。
- 关注的应用崩溃或 ANR：弹出提示。

告警会在曲线上打标记并在主窗口弹出提示。同一条告警一分钟内不重复，条件解除时在时间轴上记一笔「已恢复」。

#### 设备状态弹出为独立窗口
状态面板标题栏的 ⧉ 把设备状态弹到单独的窗口，窗口里可以单独选择设备，适合放到另一块屏幕上，一边投屏操作一边看曲线。

### 改进

#### 更多系统指标
- **IO 等待**：从 CPU 空闲里单独拆出来，在 CPU 卡片和曲线上显示。
- **资源压力（PSI）**：CPU、内存、IO 的压力曲线，比占用率更能说明有没有任务在排队。内核或 SELinux 不支持时不显示。
- **CPU 簇与限频**：「各核心」按小 / 中 / 大核分组，频率上限被温控或省电策略压低的簇会标出来。
- **温控等级**：新增「温控」卡片，显示系统温控等级和限频情况。

#### 曲线
- 所有曲线悬停时联动显示同一时刻的数值。
- 横向拖选放大，双击还原；放大时自动暂停，标题栏也可以手动暂停，采集照常进行。
- 历史从 5 分钟延长到 30 分钟，可以切换显示最近 5 / 10 / 30 分钟。
- 纵轴宽度按刻度文字自动调整，「150 MB」这类带单位的刻度不再被截断。

#### 进程表
- 列出全部进程（最多 300 个），可以按 CPU、内存、名称排序，按名称或 PID 搜索，切换显示 10 / 30 / 全部。
- 点星标把关心的进程固定在顶部，按进程名记住；没在运行时也留一行提示。
- 前台应用所在行高亮。

#### 文档
- README 和 `docs/USER_GUIDE.md` 的设备状态部分按新功能更新。
- 新增 `docs/RESPONSE_DIAGNOSIS_DESIGN.md`：后续「点击响应慢的原因诊断」的改造设计，这一版完成了其中的实时监控部分。

### 已知问题

- SurfaceFlinger timestats 是设备的全局开关。Cockpit 正常退出时会关掉它；如果 Cockpit 被强制结束，它会保持开启直到设备重启，有少量额外开销。可以手动执行 `adb shell dumpsys SurfaceFlinger --timestats -disable` 关闭。
- 关注应用处于「跟随前台」时，应用被强制停止后前台会先切到别的应用，它随后重新启动的事件可能不会标出来；固定关注后没有这个问题。
- 限频、PSI、温度告警和 SurfaceFlinger 帧统计依赖设备节点和系统版本，目前只在 Android 14 模拟器上验证过，欢迎反馈真机上的表现。
- 录制文件不会自动清理，需要在「历史」里手动删除。
