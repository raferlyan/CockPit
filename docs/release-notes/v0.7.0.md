## Cockpit v0.7.0

这一版新增投屏录屏，并把界面动画调整为平滑的淡入淡出，去掉回弹。

### 下载

| 系统 | 文件 |
|---|---|
| macOS（Apple 芯片） | `Cockpit-0.7.0-mac-arm64.dmg` |
| macOS（Intel） | `Cockpit-0.7.0-mac-x64.dmg` |
| Windows 10/11 | `Cockpit-0.7.0-win-x64.exe` |
| 产品使用说明书 | `Cockpit-v0.7.0-manual-zh-CN.pdf` |

安装包没有签名。macOS 首次打开如提示「无法验证开发者」，在 Finder 里右键 → 打开；Windows 如出现 SmartScreen 提示，点「更多信息 → 仍要运行」。

---

### 新功能

#### 投屏录屏
投屏工具栏新增「录屏」：
- 点「录屏」开始，按钮变成红点和已录时长，再点一下结束。
- 视频直接保存投屏收到的 H.264 码流，**不重新编码**：画质与投屏画面一致，几乎不占用电脑 CPU，也没有手机自带 `screenrecord` 的 3 分钟限制；边录边写盘，录多久内存都不增长。
- 保存到「影片/Cockpit」（macOS：`~/Movies/Cockpit`；Windows：`视频\Cockpit`），文件名为「设备名_日期_时间.mp4」。保存后提示文件位置、时长和大小，工具栏上短暂显示「打开录屏」。
- 设备旋转导致分辨率变化时，自动结束当前文件并开始新的一段（文件名后加 `_2`、`_3`）。
- 投屏中断、点「停止」或关闭投屏窗格时，已录的部分会自动保存。
- 分辨率与投屏相同（默认长边 1080 像素）；目前只录制画面，不录制声音。

### 改进

#### 动画改为平滑的淡入淡出
- 去掉回弹：区域收起 / 展开改为平滑减速的过渡（0.28 秒），不再冲过头再弹回。
- 对话框、右键菜单、补全提示、通知改为淡入淡出，只保留很小的位移；去掉弹性放大。
- 操作日志面板平滑滑入；去掉按钮按下的缩放。
- 系统开启「减少动态效果」时仍会自动关闭动画。

#### 文档
- 产品使用说明书和用户手册新增录屏说明，说明书更新到 v0.7.0。
- 修复说明书 PDF 中图片分页时在上一页底部留下灰色细条的问题。

### 其它

- 新增录屏封装（Annex-B 转换、avcC、分段、空文件清理）的单元测试（共 166 个测试）。
- 新增依赖 `mp4-muxer`（MIT，纯 JavaScript），用于写入 MP4。
