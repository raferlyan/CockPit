## Cockpit v0.8.0

这一版新增 GPU 与 NPU 占用显示，终端支持上下键翻历史，新建终端的入口合并成加号和下拉箭头，终端标签改为跟设备绑定；同时修复解密工具报「保存 access_token 失败」的问题。

### 新功能

#### GPU 与 NPU 占用
设备状态新增 GPU 和 NPU 卡片、「GPU 与 NPU 占用」曲线，多设备对比也可以选 GPU：
- 每 2 秒读取一次，支持高通 kgsl、`/sys/kernel/gpu`、Mali、联发科 GED、devfreq 和瑞芯微 rknpu 节点。
- 很多设备的 SELinux 不允许 shell 读这些节点。这时卡片提示需要 root；已有后台 root 会话时会自动用它读取。
- 找得到设备但驱动不提供占用数据时，卡片显示「驱动未提供占用数据」；完全找不到对应硬件节点时不显示卡片。
- 目前不支持联发科 NPU，高通 NPU 大多读不到占用。

#### 终端上下键翻历史
在 Shell 和 root 终端里，↑ / ↓ 切换历史命令。补全提示打开时，上下键仍用于选择候选项。本机终端和 Logcat 不走这套逻辑。

#### 终端标签跟设备绑定
切换设备后，只显示当前设备的终端标签，上一台设备的终端在后台继续运行，切回来时内容还在，每台设备各自记住上次打开的标签。本机终端和串口不属于某台设备，在所有设备下都显示。工具栏上的终端数量只统计当前能看到的标签。

### 改进

#### 新建终端入口合并
原来的四个新建按钮合并到标签页右侧：`+` 直接新建 Shell，旁边的下拉箭头可以选择 Logcat、本机终端（Windows 上是 PowerShell）和串口。标签多时，标签区域可以单独横向滚动，当前标签会自动滚到可见位置。

#### 终端标题简化
标签只显示 `shell`、`logcat` 或 `root shell`，不再重复设备名和序列号；鼠标悬停时显示设备名和序列号。

#### 文档
产品使用说明书更新到 v0.8.0：重写终端一章，加入 GPU 与 NPU 说明和解密工具的工作目录规则，并按新界面更新了截图。用户手册和 README 的文字说明同步更新。

### 修复

#### 解密工具报「保存 access_token 失败」
- 解密工具现在在自己所在的文件夹里运行，和双击运行时一致。之前它会继承 Cockpit 的当前目录，写缓存文件时可能失败。
- 工具所在文件夹不可写时（比如装在 Program Files），改用 Cockpit 用户数据目录下的 `decrypt-tool` 文件夹。
- 工具没有返回错误码、只打印错误信息时，不再把这行信息当成密码填入，而是直接显示报错内容和工作目录。
