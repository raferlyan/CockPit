## Cockpit v0.4.0

这一版集中解决了实际使用中遇到的问题：上传卡死、su 后状态不更新、截图路径一闪而过，同时新增 Logcat 筛选、存储逐层分析、日志导出和中英文界面。

### 下载

| 系统 | 文件 |
|---|---|
| macOS（Apple 芯片） | `Cockpit-0.4.0-mac-arm64.dmg` |
| macOS（Intel） | `Cockpit-0.4.0-mac-x64.dmg` |
| Windows 10/11 | `Cockpit-0.4.0-win-x64.exe` |

安装包没有签名。macOS 首次打开如提示「无法验证开发者」，在 Finder 里右键 → 打开；Windows 如出现 SmartScreen 提示，点「更多信息 → 仍要运行」。

### 新功能

#### Logcat 筛选与导出
Logcat 标签上方新增筛选栏，改动后立即对已缓存的日志（最多 10 万行）重新筛选，不用重开 logcat：
- **级别**：V / D / I / W / E / F，只显示不低于所选级别的日志。
- **Tag**：空格分隔多个词，Tag 包含任一词即显示；`-chatty` 这样以 `-` 开头的词表示排除。
- **关键字**：匹配整行内容，命中处反色高亮；写成 `/.../` 按正则匹配，`Aa` 切换是否区分大小写，正则写错时输入框变红并提示原因。
- **包名或 PID**：只看某个应用的日志。填包名时每 3 秒重新查一次进程号，应用重启换了 PID 也能自动跟上；未运行时显示「未运行」。
- **暂停 / 继续**：暂停滚动方便查看，新日志照常缓存，继续后补上。
- **清空**：清掉已缓存的日志。
- **导出全部 / 导出筛选结果**：保存为文本文件（去掉颜色码），弹出保存对话框自选位置。

#### 导出设备日志（/data/logger）
设备信息里新增「导出日志」：
- 默认读取设备上的 `/data/logger`，另有 `/data/log`、`/data/anr`、`/data/tombstones`、`/sdcard/Android/log` 快捷目录，也可以输入任意路径。
- 按文件名筛选：空格分隔多个关键词（全部包含才显示），支持 `*`、`?` 通配。
- 可以勾选部分文件导出、导出筛选出的全部文件，或「导出整个目录」。
- 导出位置自己选择并会被记住；需要 root 的目录在有 su 的设备上自动经 su 中转读取。
- 目录不存在时直接提示「目录不存在」，不再显示一长串 adb 命令。

#### 存储占用逐层分析
设备状态里的「存储」从只显示分区总量，改为可以逐层进入：
- 点分区进入，列出每个子目录和文件的占用，按大小排序，带比例条和占比。
- 点文件夹继续深入，面包屑和「↑ 上级」返回；也可以直接输入路径，或点 `/sdcard`、`/sdcard/Android/data`、`/data/local/tmp` 快捷目录（这些目录和 /data 同分区，分区列表里不会单独出现）。
- 没有权限的目录会提示统计偏小，有 su 的设备可以一键「用 root 重新统计」。
- 每个目录右侧的 `>_` 和顶部「在终端中打开」会新开一个 Shell 标签并 `cd` 进该目录（需要 root 的目录会先 `su`）。
- 统计结果按目录缓存，来回切换不用重新等待。

#### 截图：先预览，再选择保存或编辑
- 截图后先弹出预览窗口（显示原始分辨率），可以「保存」到「图片/Cockpit」、「另存为…」自选位置，或「放弃」。
- 「编辑标注」：画笔、矩形、箭头、文字、马赛克，6 种颜色、3 档粗细，支持撤销（Cmd/Ctrl+Z）和清除标注；线宽按截图分辨率换算，高分屏截图上也清楚。标注直接画在原分辨率图像上。
- 保存后窗口不再自动消失，显示完整路径，可以「复制路径」「打开所在目录」，看清楚后再关闭。保存的同时复制到剪贴板。

#### 应用管理
- 新增「打开」：把应用拉到设备前台；已在运行时直接切回，不会重建界面。
- 新增「安装时间」列：显示首次安装时间，覆盖安装过的还显示最近更新时间；可按包名、安装时间、更新时间排序（新的在前）。

#### 中英文界面
- 「设置 → 语言 / Language」切换简体中文与英文，立即生效，投屏和终端会话不受影响。
- 首次启动按系统语言自动选择。
- 系统对话框标题、常见错误信息、命令提示的说明也一并切换。

#### 终端字体
- 「设置」里新增独立的「终端字体」，作用于 Shell、Logcat、串口。
- 默认使用 Windows Terminal Preview 的默认字体 **Cascadia Mono**，已随应用打包，macOS 上同样生效；也可以选 JetBrains Mono、Fira Code、更纱黑体等或填写本机字体名。

### 改进

- **终端 Ctrl+C / Ctrl+V**：macOS 上也支持选中文字后 Ctrl+C 复制、Ctrl+V 粘贴（Cmd+C / Cmd+V 照常可用）；没有选中文字时 Ctrl+C 仍是中断当前命令。Windows 上 Ctrl+V 可直接粘贴。
- **设备状态布局**：顶部卡片统一高度（没有副标题的也留出同样的行高）；宽布局下 CPU 与内存、温度、网卡、各核心、进程、存储各成一张带边框的卡片，标题下有分隔线，同一行卡片等高；存储占满整行。窄布局下各分区之间加分隔线。
- 设备信息的标签列按最长标签自适应宽度，英文界面下不再重叠。

### 问题修复

- **上传卡死、窗口关不掉**（如往 `/system_ext/priv-app/SystemUI` 上传 SystemUI.apk）：
  - 上传过程中随时可以「取消上传」或点 × 关闭窗口（会先确认），关闭即取消。
  - 设备 30 秒不接收数据自动中止；数据发完后 2 分钟内设备没确认写入也会中止，不再无限等待。
  - 设备断开时自动取消进行中的上传。
  - 取消或中断后自动删除设备上写了一半的文件。
  - 经 root 写入系统目录时先复制成临时文件再改名替换，不再先删除正在运行的 APK。
  - 往只读分区上传时，错误信息里说明需要先 `adb root && adb disable-verity && adb remount`（或 su 后 `mount -o rw,remount`）。
  - su 授权弹窗没人点时最多等 2 分钟，不再等 30 分钟。
- **在应用内 Shell 里 su 后，左侧设备列表仍显示 su**：现在终端提示符变成 `#` 后，设备列表和设备信息的标记会变成 **root**；该终端退出 root 或关闭后恢复。
- 从存储分析等处「在终端中打开」时，等设备端 shell 出现提示符后再输入命令，不再因为 shell 尚未启动而丢失输入。
