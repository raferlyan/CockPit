Android 调试桌面工具 · v0.2.0

投屏、终端、负载监控、文件传输，一个窗口搞定

Cockpit 把调试 Android 设备时常开的 scrcpy、终端、串口工具和一堆 adb 命令收进同一个窗口。只依赖电脑上的 adb，手机上不用装任何 App。

为什么用它

以前要开好几个窗口的事

以前现在用 Cockpit
scrcpy 另开一个窗口投屏投屏嵌在主窗口，最多 4 台同时投
多台设备要记序列号，敲 adb -s <序列号> shell选中设备点「+ Shell」，标签上直接显示设备名和序列号
top、dumpsys battery、cat /sys/class/thermal/… 轮着看CPU、内存、温度、电池、网络、进程、存储每秒刷新，带 5 分钟曲线
记不住 pm / am / dumpsys 的子命令和包名边输入边提示命令、选项、设备上的包名和历史命令
adb push / adb pull 手敲路径拖文件进来，选好设备目录就上传；设备上的文件点一下下载
串口工具另装一个软件同一个终端区开串口标签

界面

默认看状态，需要时再投屏

中间区域默认显示设备状态。点右侧「投屏」，投屏画面换到中间，状态挪到右侧继续刷新；点「收起投屏」回来。设备信息始终固定在右上方，只有下面的状态区滚动。

设备状态

每秒刷新的负载，一眼看出谁在吃资源

  • CPU 总占用和 loadavg，每个核心的占用和当前频率（MHz），离线核心会标出来
  • 内存与 Swap / ZRAM，CPU / GPU / 电池 / 机身温度，电池电量、电压和充电状态
  • 网络上下行速率，进程 Top 10，各分区存储占用
  • 最近 5 分钟曲线；连了多台设备可以切到「对比」，把 CPU、内存或温度画在一张图上

投屏与操控

点一下「投屏」，画面直接换到中间

基于 scrcpy 服务端，画面用 WebCodecs 硬件解码后嵌在主窗口里。

  • 鼠标左键触摸、右键返回、中键主页、滚轮滚动；键盘直接打字，中文输入法可用
  • 电脑和手机双向剪贴板，工具栏有返回、主页、多任务、音量、电源、通知栏、旋转
  • 最多 4 台同时投屏，网格并排或单台切换，切换时其它设备不断流
  • 标题显示设备名和序列号；把文件拖到画面上直接打开传输窗口

终端

会提示命令和包名的 adb shell

Shell、Logcat、串口在同一个终端区，多标签，标签上显示设备名和序列号，$ 是普通用户，# 是 root。

  • 输入时弹出命令、子命令、选项和参数候选，每项带中文说明
  • 在 pm clear、am force-stop、monkey -p 后提示设备上已安装的包名，输入 tencent 就能找到 com.tencent.mm
  • 执行过的命令记为历史，下次排在最前
  • 复制粘贴：⌘C ⌘V，Windows 上 Ctrl+Shift+C Ctrl+Shift+V，也可以右键菜单
  • 把电脑上的文件拖进终端，插入它的绝对路径

文件传输

选好设备目录再上传，下载也能指定位置

  • 左边列出本机文件的绝对路径，拖进来或点「选择文件…」
  • 右边选设备目录：直接输入、点快捷目录 /sdcard/Download /sdcard /data/local/tmp，或逐级浏览
  • 目录不存在自动创建，单个文件失败不影响其它文件
  • 目录里的文件或文件夹点「下载」，保存到电脑上指定的目录

上手

三步开始用

  1. 装 adb安装 Android SDK Platform-Tools。Cockpit 自动在 ANDROID_HOME、PATH 和 SDK 默认位置查找，底部状态栏显示找到的路径。
  2. 装 Cockpit下载对应平台的安装包。macOS 首次打开在 Finder 里右键 →「打开」；Windows 遇到 SmartScreen 点「更多信息」→「仍要运行」。
  3. 连设备手机打开 USB 调试并允许授权，左侧出现绿点即在线。无线调试在左下角输入 IP:端口。
